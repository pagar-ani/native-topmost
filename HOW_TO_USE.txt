====================================================================
  native-topmost - Lightweight Windows Always-on-Top
====================================================================

Keeps windows pinned on top, even over full-screen games, video players,
and multi-monitor setups.

Footprint: 27 KB standalone executable | ~2 MB RAM | Zero dependencies

--------------------------------------------------------------------
  PREREQUISITE
--------------------------------------------------------------------
If Microsoft PowerToys is installed:
Open PowerToys Settings -> "Always on Top" -> Turn it OFF
(prevents hotkey conflicts).

--------------------------------------------------------------------
  HOW TO INSTALL
--------------------------------------------------------------------
1. Double-click install.bat.
   - Installs TopmostDaemon.exe into %LOCALAPPDATA%\TopmostDaemon\
   - Automatically registers a background startup task on Windows logon.
   - Optional: Right-click install.bat and select "Run as Administrator"
     if you need to pin elevated windows like Task Manager.

--------------------------------------------------------------------
  HOW TO USE
--------------------------------------------------------------------
- Hotkey: Press [ Ctrl + Win + T ] to pin or unpin.
- Targeting:
  * Standard windows: Focus or click the window, then press hotkey.
  * Picture-in-Picture: Hover mouse over the player and press hotkey.
  * Hover unpin: Hover mouse over any pinned window and press hotkey.
- Sound feedback:
  * Asterisk chime (MB_ICONASTERISK) = Window pinned.
  * Default beep (MB_OK)             = Window unpinned.
  * Stop chime (MB_ICONHAND)         = Ignored (shell or Admin window).

--------------------------------------------------------------------
  HOW TO UNINSTALL
--------------------------------------------------------------------
1. Double-click uninstall.bat.
   - Stops the process, removes the startup task, and deletes the files.
